| 操作与登录日志 | 按操作人、动作、对象、日期查询；记录登录成功和失败；展示经过裁剪的审计摘要 |
| IM 会话 | 单聊/群聊列表，按会话、成员、日期、发送者、文本筛选；填写原因并成功写入审计后才返回消息；附件到期后主动重新审计获取 |
| 群成员 | 成员列表、角色调整、禁言/解除禁言、移出群；复用原群聊/圈子服务；保护群主和自己 |
| VIP | 会员等级、到期时间、赠送/升级、完整授予记录 |
| 充值 | 充值订单状态、付款凭证、确认到账后审核/拒绝；收款码上传、配置、启停 |
| 靓号 | 全部库存查询、批量添加、启停、持有人、有效期、订单历史；热门推荐单独管理 |
| 举报与内容 | 好友、群、帖子举报；帖子内容详情、下架原因和恢复 |
| 内容运营 | 敏感词搜索及批量增删；系统公告预览、确认、发布和返回的投递结果 |
| 邀请码 | 个人邀请码、邀请关系及奖励状态；批量活动邀请码、邀请人、到期时间、启停和人数上限；注册归因与使用计数在同一事务内 |
| 活动广告 | 图片/跳转链接、排序、启停、投放时间、版本冲突保护；App 圈子广场广告卡片按时间展示与点击跳转 |

## 角色分工

- 超级管理员：全部权限。
- 运营：数据看板、用户基础信息、圈子、会员/靓号、敏感词、邀请、广告和公告。
- 审核：数据看板、用户基础信息及状态、圈子、IM 与群成员、举报与内容审核、审计日志。
- 客服：用户基础信息、IM 查询、客服配置、充值审核。
- 敏感联系方式原文和管理员权限分配仅超级管理员可用。
- 新增管理员默认没有中台权限，需要超级管理员先分配角色。

## 使用边界

- IM 只接入当前自研聊天持久化数据，旧 OpenIM 历史未接入。
- 已撤回、删除、清空及到期焚毁内容不提供查看；附件链接有期限，续用需再次主动审计。
- 邀请奖励仍按原有资格与结算流程发放，生成活动邀请码不会直接发奖励。
- 广告支持关闭投放；暂不提供删除接口。App 最多显示 10 条有效广告，配置变化在焦点/前台刷新或 60 秒轮询时同步，到期卡片在一秒内隐藏。
- 中台构建有单个 JS 包超过 500 KB 的提示；当前生产构建成功。
- 整体审查结果与修复记录见 `final-review.md` 及后续报告。
